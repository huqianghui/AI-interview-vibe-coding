阅读入口：index.html
用浏览器直接打开即可。页面、图表和交互数据都已内嵌，不需要启动服务或联网。
如需复核原始证据，请保留整个目录；HTML 中 evidence/ 开头的链接指向同目录的证据文件。

建议阅读顺序
1. 第 01 节：结论、样本规模与限制。
2. 第 02–03 节：先理解两条语音路径，再播放整场流程与单条真实记录。
3. 第 04–08 节：选择 operation，看恢复、媒体、前后端 API 和评分的具体记录。
4. 第 09–11 节：运行配置、发布、优化建议、指标口径与证据入口。

- 查看 15 条成功建连／握手／回答事件的独立阶段。
- 选择 6 条重点 operation，展开父子调用及原始 ID。

新增动态图的读法
- 整场流程是逻辑步骤，方块大小与间距不代表耗时；不同阶段的中位数不能相加成一场真实面试总时长。
- 真实回放均保留一条记录自己的时间原点，播放速度经过缩放，实际时间读坐标。
- “停止说话到下一句”和“包含讲话时间”是同 7 条回答记录的两个观察窗口。
- Judge 重叠图使用后端时间，不与浏览器单调时钟强行对齐。
- 评分样本来自 10/09，语音样本来自 10/10，二者仅为逻辑衔接，不冒充同一场完整面试。
- 各阶段 P50 优先使用原始 *_ms 字段；回放的 t_* 端点分别取整，可能相差 1–2 ms。
- 263 ms = 7 个精确关联请求中逐对计算 Fetch - Server 后的中位数，不是纯 RTT 或单向延迟。
